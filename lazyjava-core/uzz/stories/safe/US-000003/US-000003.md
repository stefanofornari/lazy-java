## safe/US-000003 — Validate Required Non-Empty and Non-Blank Strings

### User Story

```
AS A Developer
I WANT validation helpers for empty and blank strings
SO THAT I can reject missing text inputs with clear IllegalArgumentException messages
```

#### Status
DONE

#### Dependencies
- None

#### Technical Context & Constraints
* **Target System**: JVM library module `lazyjava-core`.
* **Toolchain / Rules**: Uses Apache Commons Lang3 `StringUtils` in `ste.lazyjava.safe.Safe`; JUnit 5 + AssertJ verification.
* **Phase**: Current scope baseline (implemented).

#### Notes
1. Implemented methods: `requireNonEmpty(String, String)` and `requireNonBlank(String, String)`.
2. `requireNonEmpty` rejects null and empty strings with `<name> must be non empty`.
3. `requireNonBlank` rejects null, empty, and whitespace-only strings with `<name> must be non blank`.

### Acceptance Criteria

```gherkin
Scenario: Accept valid string input
  Given a string that contains required text
  When the consumer code calls requireNonEmpty or requireNonBlank
  Then validation completes without throwing an exception

Scenario: Reject missing or blank string input
  Given a string that is null, empty, or whitespace-only as applicable to the validation rule
  When the consumer code calls requireNonEmpty or requireNonBlank
  Then an IllegalArgumentException is thrown with a message that includes the parameter name and the expected requirement
```
