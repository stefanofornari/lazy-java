## safe/US-000001 — Conditionally Execute Code for Null and Non-Null Values

### User Story

```
AS A Developer
I WANT null-safe conditional helpers for nullable values
SO THAT I can express null-handling logic clearly without repetitive if statements
```

#### Status
DONE

#### Dependencies
- None

#### Technical Context & Constraints
* **Target System**: JVM library module `lazyjava-core` (Java 11 source/target per module POM).
* **Toolchain / Rules**: Maven build; JUnit 5 + AssertJ tests; implementation in `ste.lazyjava.safe.Safe`.
* **Phase**: Current scope baseline (implemented).

#### Notes
1. Implemented in `lazyjava-core/src/main/java/ste/lazyjava/safe/Safe.java` as default methods: `ifNotNull(Object, Runnable)`, `ifNull(Object, Runnable)`, `ifNull(Object, Runnable, Runnable)`, and `safe(T, Consumer<T>)`.
2. `safe` invokes the consumer only when the value is non-null and passes the value through.
3. Behavior is verified by `ste.lazyjava.safe.SafeTest`.

### Acceptance Criteria

```gherkin
Scenario: Run action when value is present
  Given a nullable object value that is not null
  When the consumer code uses Safe.ifNotNull or Safe.safe
  Then the provided action executes with the expected value

Scenario: Skip action when value is null
  Given a nullable object value that is null
  When the consumer code uses Safe.ifNotNull, Safe.ifNull, or Safe.safe
  Then the null-branch behavior executes when provided and non-null actions are not executed
```
