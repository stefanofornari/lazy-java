## safe/US-000002 — Validate Required Objects and Fully Populated Collections

### User Story

```
AS A Developer
I WANT validation helpers that reject null objects and null elements in arrays or lists
SO THAT I can enforce required inputs with clear IllegalArgumentException messages
```

#### Status
DONE

#### Dependencies
- None

#### Technical Context & Constraints
* **Target System**: JVM library module `lazyjava-core`.
* **Toolchain / Rules**: `ste.lazyjava.safe.Safe` default methods; Apache Commons Lang3/lambda-loop are module dependencies; tests use JUnit 5 + AssertJ.
* **Phase**: Current scope baseline (implemented).

#### Notes
1. Implemented methods: `requireNonNull(Object, String)`, `requireFullyNonNull(Object[], String)`, and `requireFullyNonNull(List<?>, String)`.
2. Error messages use the provided parameter name: `<name> must not be null`.
3. `requireFullyNonNull` for arrays/lists validates the container itself and then validates each element.

### Acceptance Criteria

```gherkin
Scenario: Accept valid required values
  Given a non-null object, or an array/list whose container and elements are all non-null
  When the consumer code calls requireNonNull or requireFullyNonNull
  Then validation completes without throwing an exception

Scenario: Reject null container or element
  Given a null object, a null array/list container, or an array/list containing a null element
  When the consumer code calls requireNonNull or requireFullyNonNull
  Then an IllegalArgumentException is thrown with a message that includes the parameter name and "must not be null"
```
