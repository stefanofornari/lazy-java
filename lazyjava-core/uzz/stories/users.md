# Users

Actors referenced by the `AS A [role]` clause of user stories. This list is
authoritative: stories must not invent roles that are not listed here.

- **Developer**: A Java developer who uses `lazyjava-core` as a dependency and calls its runtime APIs (such as `Safe`) in application or library code.
