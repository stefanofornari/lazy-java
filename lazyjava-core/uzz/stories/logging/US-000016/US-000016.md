## logging/US-000016 — Document the File Log Handler

### User Story

```
AS A Developer
I WANT to read how to configure the file log handler, its tokens and its failure behaviour
SO THAT I can use it correctly without reading the source
```

#### Technical Context & Constraints
* **Target System**: JVM library module `lazyjava-core`, classpath.
* **Toolchain / Rules**: Java 11 + Maven; JUnit 5 + AssertJ; `java.util.logging` only; code in `lazyjava-core` (`ste.lazyjava.logging`). Reference docs per `logging/scope.md`.

#### Notes
1. Class Javadoc with a complete `logging.properties` example, the list of settings and defaults, the tokens, and the failure behaviour.
2. A short section in the module docs (`docs/modules.md`) and the README line for `lazyjava-core` (already updated).
3. Mention that the handler is loaded from the classpath only (module path is out of scope).

### Acceptance Criteria

```gherkin
Scenario: Javadoc documents the configuration
  Given the `ste.lazyjava.logging.FileLogHandler` class
  When  a developer reads its Javadoc
  Then  it shows an example logging.properties, every setting with its default, the tokens and what happens on failure

Scenario: Module docs mention the handler
  Given the GitHub Pages module documentation
  When  a developer reads the lazyjava-core section
  Then  the file log handler is described with a link to the example
```
