## logging/US-000012 — Create the Log Folder When Missing

### User Story

```
AS A Developer
I WANT to the folder of the log file to be created for me
SO THAT logging works on first run without a manual setup step
```

#### Technical Context & Constraints
* **Target System**: JVM library module `lazyjava-core`, classpath.
* **Toolchain / Rules**: Java 11 + Maven; JUnit 5 + AssertJ; `java.util.logging` only; code in `lazyjava-core` (`ste.lazyjava.logging`). Reference docs per `logging/scope.md`.

#### Notes
1. The standard `FileHandler` does not create folders. The folder part of the expanded pattern is created (`Files.createDirectories`) before the file is opened.
2. Folders written with `%h` or `%t` are resolved before creation; a folder that contains `%g` or `%u` is left to `FileHandler`.
3. `%` escaped as `%%` in the pattern is a literal `%` in the folder name.

### Acceptance Criteria

```gherkin
Scenario: Missing folders are created
  Given a pattern in a folder that does not exist, several levels deep
  When  the handler is created
  Then  the folders are created and the log file exists

Scenario: Literal percent in a folder name
  Given a folder whose name contains an escaped `%%`
  When  the handler is created
  Then  the folder with a literal `%` is created and used
```
